# stands in for the beam-on data.  SystematicsCalculator detects it as fake data
# (it carries MC truth histograms) and builds the FakeDataMC universe from its
# CV-weighted reco spectrum.
#
# Exposure convention (NuWro overlay's native generated POT):
#   onBNB POT      = 6.6504e20   (summed nuselection/SubRun "pot" of the overlay)
#   onBNB triggers = 15820704    (real-data extBNB scaling 7809962 multiplied by
#                                 6.6504/3.283, so the EXT cosmic background is
#                                 scaled to the fake-data exposure)
# All MC/EXT/dirt/detVar samples are scaled to this onBNB POT, so the background
# prediction and response matrix match the NuWro fake data.  The extracted cross
# section is POT-independent, so this gives a high-statistics closure test: the
# unfolded result should reproduce the NuWro truth cross section.
#
# To instead run at the real beam-on exposure (3.283e20, realistic stat errors),
# the NuWro reco would need pre-scaling by 3.283/6.6504 — not done here because
# the framework takes the fake-data histogram unscaled.
