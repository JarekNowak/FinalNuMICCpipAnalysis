# ccpi_xsec_config_numi.txt
# CrossSectionExtractor config for the CCpi+ pmu measurement (UnfolderNuMI).
# Points at the Run1 universe file + the CCpi systcalc config + file properties.
#
# UnivFile : output of run_universe_maker.sh (ccpi_pmu_bin_config.txt)
# SystFile : ccpi_systcalc_numi.conf (stock minus orphan beamline block)
# FPFile   : same processed-file list / POT-trigger table used everywhere
# Unfold   : D'Agostini iterative, 4 iterations (= main analysis IBU_ITER=4)
# Prediction: central-value MicroBooNE tune from the CV universe
#
# NOTE: this used to point at ccpi_Run1_pmu_range_univmake.root, built from
# ccpi_pmu_range_bin_config.txt. That binning is unusable: it bins reco on
# candidate_muon_mom_range, which stays at its 0.0 reset value for uncontained
# muons, so every uncontained-muon event fell below the first reco bin (0.100)
# and dropped out of the reco spectrum while still counting in truth. The
# universe file no longer exists either. This pair of configs exists to compare
# unfolding methods, so it now uses the main pmu universe file, whose binning
# was corrected to candidate_muon_mom_reco (range if contained, MCS otherwise).
UnivFile /data/uboone/processed/ccpi_Run1_pmu_univmake.root
SystFile configs/ccpi_systcalc_numi.conf
FPFile configs/file_properties_numi.txt
Unfold DAgostini iter 4
Prediction uBTune "MicroBooNE Tune" univ CV
