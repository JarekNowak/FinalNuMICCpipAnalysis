\section*{1 Overview}

This note describes the extraction of the νμ charged-current single charged pion cross section on argon using MicroBooNE Run 1 FHC data from the NuMI beam. It is the NuMI counterpart of the BNB analysis of the same final state, and is intended to be read alongside that note, which contains fuller descriptions of the selection variables and the boosted decision trees.

The measurement is performed with the common \texttt{xsec\_analyzer} framework: event selection via the \texttt{CC1mu1piXp} selection class, universe construction via \texttt{univmake}, and unfolding via the Wiener-SVD implementation in \texttt{CrossSectionExtractor}. Section 2 describes the software and samples, Section 3 the signal definition and selection, Section 4 the uncertainty treatment, Section 5 the cross-section extraction and unfolding, Section 6 the fake-data tests, and Section 7 the results.

\subsection*{2.4 Corrections applied since the previous iteration}

The following were found and fixed during a code review of this analysis. All of them affect the numbers a run would produce, which is why no results from before them should be carried forward:

\begin{itemize}
\item \textbf{Flux normalisation (dominant correction).} The integrated NuMI flux constant in the cross-section conversion factor was 2.372512 × 10⁻⁹ νμ/cm²/POT, taken from the superseded \texttt{uboone\_numi\_flux\_histograms.root} (which included an unphysical \textasciitilde{}25–30 MeV artifact spike). The authoritative value from the flux-file author, using the new GEANT4 flux integrated above 60 MeV, is 4.43515 × 10⁻¹⁰ (νμ) + 2.37644 × 10⁻¹⁰ (ν̄μ) = 6.81159 × 10⁻¹⁰ νμ/cm²/POT — a factor \textbf{3.48 smaller}. Because the cross section divides by the flux, the old constant made every extracted cross section \textasciitilde{}3.5× too \emph{small}. The correction was confirmed four independent ways: standalone NuWro (2.7× low) and GENIE (3.2× low) run on the old flux; the flux author's numbers (3.48×); and a GENIE closure in which the framework tune scaled by 3.48× matches a standalone GENIE on the corrected flux to 3\%. Fixed in \texttt{FiducialVolume.hh} (\texttt{integrated\_numu\_flux\_in\_FV}). The flux is the active-volume-averaged flux used as an approximation for the fiducial-volume flux — a documented \textasciitilde{}few-\% residual; no fiducial-volume correction is applied (the target count is done separately in the same conversion factor).
\item \textbf{Muon momentum estimator.} The estimator combining range (contained) and MCS (uncontained) was computed but never written to the output tree, so the unfolding binned on MCS alone. It is now branched as \texttt{candidate\_muon\_mom\_reco} and \texttt{ccpi\_pmu\_bin\_config.txt} uses it.
\item \textbf{Pion momentum estimator.} Reco pion momentum was a proton-hypothesis range \emph{kinetic energy} binned against a true \emph{momentum} on identical bin edges. It is now the muon-hypothesis range momentum.
\item \textbf{Per-category systematics.} Six \texttt{MCFullCorrCategory} entries evaluated to identically zero and have been removed; see §4.6.
\item \textbf{Background true bins.} \texttt{MakeConfig} had stopped emitting them, so any regenerated bin config would have had no background subtraction at all.
\item \textbf{Diagnostic histograms} are now filled with the CV weight (\texttt{spline\_weight\_ × tuned\_cv\_weight\_}).
\end{itemize}

\section*{3 Signal and Selection}

\subsection*{3.1 Signal definition}

An event is signal if, in truth:

\begin{itemize}
\item the neutrino vertex is inside the fiducial volume: 10 < x < 246 cm, −101 < y < 101 cm, 10 < z < 986 cm;
\item the interaction is charged-current;
\item the neutrino is νμ (\texttt{|mc\_nu\_pdg| == 14}, see §8.3);
\item there is exactly one muon above threshold;
\item there is exactly one charged pion;
\item there are no neutral pions, no kaons and no heavier mesons;
\item any number of protons is allowed, with no momentum threshold (the "Xp" in \texttt{CC1mu1piXp});
\end{itemize}

and the event falls in the measured phase space:

\begin{itemize}
\item p\_μ > 0.15 GeV/c
\item p\_π > 0.175 GeV/c
\item θ\_μπ < 2.6 rad
\end{itemize}

The phase-space cuts are applied identically in \texttt{define\_signal()} and \texttt{categorize\_event()}, so signal and category assignment cannot disagree. The counting of "one muon / one charged pion" uses no momentum threshold (any \texttt{|p| > 0}); the momentum thresholds enter only through the measured phase space above.

\textbf{Threshold validation.} The two momentum thresholds sit at the selection efficiency turn-on, measured against a \textbf{threshold-free} true signal (the CC νμ 1μ1π± topology with the momentum/angle cuts removed):

\begin{tabularx}{\textwidth}{|>{\raggedright\arraybackslash}X|>{\raggedright\arraybackslash}X|>{\raggedright\arraybackslash}X|>{\raggedright\arraybackslash}X|}
\hline
\textbf{} & \textbf{below threshold} & \textbf{above threshold} & \textbf{turn-on} \\
\hline
p\_μ > 0.15 & \textasciitilde{}0–1.5 \% & \textasciitilde{}9–12 \% & 0.145 → 0.155 GeV/c \\
p\_π > 0.175 & \textasciitilde{}0–3 \% & \textasciitilde{}12–16 \% & 0.165 → 0.185 GeV/c \\
\hline
\end{tabularx}

Both thresholds are therefore \textbf{correctly placed} — lowering them would add near-zero-efficiency phase space, raising them would discard measurable signal. The odd value 0.175 is precisely the pion turn-on knee. The muon momentum (range/MCS, §2.4) is essentially unbiased near threshold.

\textbf{Pion momentum bias (open item).} The pion momentum is reconstructed from track range under the \textbf{muon hypothesis} (\texttt{track\_range\_mom\_mu}, the only range-momentum branch available). It is biased low for pions and increasingly so with momentum — mean(reco − true) grows from ≈ 0 at threshold to −0.05 at 0.25 and \textbf{−0.15 GeV/c (\textasciitilde{}40 \%) at 0.40} — from two effects: the μ-vs-π mass hypothesis (\textasciitilde{}−0.025) and, dominantly, \textbf{pion hadronic re-interaction} shortening the range, which effectively saturates the reconstructed momentum near 0.2–0.25 GeV/c. The p\_π response is therefore \emph{shifted} (not merely smeared) above p\_π ≈ 0.3 GeV/c, which is why the p\_π binning above this must be coarse (§3.8). A pion-hypothesis range correction is recommended (§8.7).

\subsection*{3.7 Selection efficiency}

The efficiency versus each true observable is the response-matrix column sum. The efficiency is a property of the selection and is applied inside the unfolding operator, not as a separate bin-by-bin correction.

\subsection*{3.8 Binning optimisation}

The binning drives two of the three dominant systematics (§4.8): the statistical term (fewer, wider bins → more events per bin) and the unfolding-amplified propagation of the correlated flux/cross-section uncertainty (bins narrower than the detector resolution give near-degenerate response columns that the Wiener-SVD inversion amplifies). The current binning — inherited, roughly uniform — is finer than the resolution in several places (e.g. 22 uniform 0.1-GeV p\_μ bins against a 15–70 \% momentum resolution).

The resolution was measured per observable as the RMS of (reco − true) for selected signal, and variable-width bins were designed greedily to be \textbf{≥ the local RMS resolution wide} and to hold \textbf{≥ 45 selected-signal events} (\textasciitilde{}15 \% statistical target):

The \textbf{statistical term roughly halves} in the statistics-heavy observables (p\_μ 20 → 8 \%, cos θ\_μ 18 → 8 \%, cos θ\_π 25 → 12 \%), and the \textbf{cross-section (unfolding-amplified) term also drops} (cos θ\_π 18 → 9 \%) because the resolution-matched bins give a better-conditioned response that the Wiener-SVD amplifies less. \section*{5 Cross-section Extraction}

The flux-integrated differential cross section in truth bin α is obtained by subtracting background from the measured event rate, unfolding to truth space, and dividing by the integrated flux Φ, the number of argon targets T, and the bin width:

\begin{verbatim}
dσ/dx |α  =  (1 / (T · Φ · Δx_α)) · Σ_a U_αa (D_a − B_a)
\end{verbatim}

where \texttt{D\_a} is the measured rate in reco bin a, \texttt{B\_a} the estimated background, and \texttt{U\_αa} the unfolding matrix, which absorbs both the reco→truth mapping and the efficiency.

Targets are counted as \textbf{argon nuclei} in the fiducial volume, so the result is per-nucleus, not per-nucleon — matching the BNB convention (\texttt{T = 1.03 × 10³⁰} nuclei there). For NuMI the fiducial volume additionally excludes the dead region 675.1 < z < 775.1 cm.

Results are quoted in units of \textbf{10⁻³⁸ cm² / Ar}, differential in the observable (so 10⁻³⁸ cm² / GeV / Ar for momenta, 10⁻³⁸ cm² / rad / Ar for angles).

Both the NuMI unit factor (now \texttt{1e38}) and the bin-width division in \texttt{Unfolder.C} were corrected to this convention; \texttt{Unfolder} and \texttt{UnfolderNuMI} now agree bin-for-bin (§8.1).

\subsection*{5.1 Unfolding}

Wiener-SVD with the filter enabled and second-derivative regularisation (\texttt{Unfold WienerSVD 1 second-deriv}), chosen over D'Agostini after a variant study — it suppresses the bin-to-bin oscillation arising from sparse Run 1 statistics. D'Agostini with 4 iterations remains available as a cross-check via \texttt{configs/ccpi\_xsec\_config\_numi\_range\_dagost.txt}.

As in the BNB analysis, the unfolded result must be compared to predictions smeared by the additional smearing matrix A\_C. The second-derivative regularisation matrix C used inside the Wiener-SVD is shown below.

\begin{figure}[htbp]\centering
\includegraphics[width=0.55\textwidth]{/home/t2k/nowak/MicroBooNE/working_xsec_analyzer/xsec_analyzer/unfold_output/plot_regularization_matrix.pdf}
\caption{Second-derivative regularisation matrix $C$ used in the Wiener-SVD (tridiagonal, Neumann boundary).}
\end{figure}

The Wiener-SVD proceeds by whitening the reco covariance (Cholesky of its inverse), pre-scaling the response, taking the SVD of the regularised response, and applying a per-mode Wiener filter W(t) = numer/(numer+1) with numer = (D\_C · Vᵀ C x\_prior)². The additional smearing matrix A\_C = C⁻¹ V W Vᵀ C and the unfolding operator R\_tot are built from the same decomposition; predictions are compared to data in A\_C-smeared space, so the smearing cancels in closure tests (§6.7).

\subsection*{6.2 Fake-data normalisation offset}

The unfolded fake data sits \textasciitilde{}1.29× above the framework GENIE tune (the numuMC CV prediction), even though both are the same GENIE G18\_10a tune. This was traced to a \textbf{flat} difference in events-per-POT between the detVar-CV sample and the numuMC overlay: the ratio is 1.293 integrated and 1.294 in the dominant catch-all true bin, i.e. present across \emph{all} event types, with the signal-bin shape agreeing within Poisson statistics. It is therefore a POT / flux bookkeeping difference from using the Run-3b detVar-CV sample as Run-1 fake data — consistent with the framework's own caveat that detVar samples exist only for Run 3b and are applied globally (\texttt{SystematicsCalculator.cxx}) — not a physics or generator difference and not a framework bug.

The familiar "data ≈ 2× above the generators" then decomposes as \textbf{1.29× (fake-data normalisation) × \textasciitilde{}1.3× (A\_C smearing)}. It can be removed by entering the fake data with an effective POT of 7.63 × 10²⁰ × 1.293 = 9.87 × 10²⁰ (and rebuilding the universes); this is documented but left uncorrected in \texttt{configs/file\_properties\_numi.txt}, since it does not affect the closure and vanishes entirely once the real beam-on sample replaces the fake data.

Neither factor is a physics offset. The genuine physics difference — the measured CC1π cross section sitting \textbf{below} the GENIE v3 prediction — is established independently in the parallel analysis (§6.7): the flat data/GENIE deficit of \textasciitilde{}0.65–0.70 in that pipeline is the well-documented GENIE v3 CC1π⁺ over-prediction on argon (\textasciitilde{}25–35 \%), not an unfolding artefact.

\subsection*{6.4 NuWro overlay vs standalone NuWro (shape study)}

The NuWro overlay previously used as fake data was compared bin-by-bin against a standalone NuWro 21.09 run on the same flux. Their cos θ\_μ distributions differ in \textbf{shape}, not just normalisation: the overlay/standalone ratio swings from 0.64 (backward) to 1.88 (mid-angle) and back to 0.65 (forward), while the integral ratio is only \textasciitilde{}1.1. The cause is \emph{not} the flux — the two samples have identical signal-weighted mean neutrino energies (1.93 vs 1.88 GeV, 3\%) — but a NuWro version/configuration difference in the muon angular distribution at fixed energy. This is why the NuWro overlay was retired in favour of the independent-GENIE fake data (§2.2), and it is a reminder that an overlay fake sample is not a clean stand-in for an external generator prediction.

\subsection*{6.6 Cross-section model excursions (M\_A)}

The sensitivity to the axial mass was probed in three steps.

\textbf{CCQE axial (AxFFCCQEshape) ±σ — negligible.} The framework already computes this unisim; its effect on the CC1π signal is \textbf{±0.08 \%} (total), ≤0.5 \% per bin. Expected: CC1π is resonance-dominated, so the CCQE axial form factor barely touches it. This is \emph{not} the relevant axial mass for this channel.

\textbf{Resonance axial mass M\_A\textasciicircum{}RES ±σ (prediction).} The standalone GENIE events were reweighted with \texttt{grwght1p -s MaCCRES} at ±1σ. The effect on the CC1π prediction is large and \textbf{asymmetric}: \textbf{−5.9 \% at −1σ, +32.5 \% at +1σ} (consistent across all five observables). The asymmetry is intrinsic to GENIE's RES reweighting (the −1σ weights are bounded 0–1.15 while +1σ has a tail to \textasciitilde{}2.8). The shift is \textbf{Q²-dependent}: strongest at backward/high-angle muons (+58 \% at +1σ, cos θ\_μ ≈ −1) and weakest forward (+17 \%, cos θ\_μ → 1), because backward muons carry higher Q² where the axial form factor's M\_A dependence is strongest. The ±σ band is shown in the figure below. M\_A\textasciicircum{}RES is the \textbf{dominant single-parameter cross-section systematic} for this measurement.

\textbf{M\_A\textasciicircum{}RES ±σ through the full unfolding.} M\_A\textasciicircum{}RES-shifted pseudo-data was built by reweighting the fake data's true signal by the per-true-bin factor f(t) and its measured reco by the migration-propagated g(r) = Σ\_t mig(t,r) f(t) / Σ\_t mig(t,r), then unfolded with the nominal response. The reweighted \textbf{truth} shifts by −6.5 \% / +33.3 \% (matching the prediction, confirming the reweight), and the \textbf{closure holds} for both variations (p = 0.95–0.98). The impact on the \textbf{unfolded total} is \textbf{−5.5 \% / +28.2 \%} — slightly smaller than the truth shift because the Wiener-SVD regularisation and A\_C smearing damp the excursion by \textasciitilde{}15 \% (more so for the larger +1σ). So the analysis propagates the M\_A\textasciicircum{}RES systematic correctly, with a mild regularisation-induced dilution.

\subsection*{6.7 Independent cross-pipeline validation}

The extraction was cross-checked against a \textbf{fully framework-independent} analysis of the same Run-1 NuMI FHC final state (selection, response building, and Wiener-SVD / D'Agostini unfolding written as standalone macros), documented in \texttt{XSecCCPip/analysis\_report.md} and \texttt{XSecCCPip/report/\{analysis,framework\}\_note.tex}. Two levels of cross-check were run.

\textbf{Cross-pipeline closure (that analysis, §16).} The NuWro fake-data closure was also run \emph{through} the official \texttt{xsec\_analyzer} framework and compared to the standalone-macro pipeline. NuWro unfolds to ≈ 2× the GENIE MicroBooNE tune in every observable, uniformly in shape (σ\_NuWro/σ\_GENIE = 2.19–2.51), and the two independent pipelines agree. The flat \textasciitilde{}2× is a genuine NuWro-vs-GENIE-tune CC1π model difference in this phase space (NuWro is used at its raw cross section, no tune applied), \emph{not} an unfolding bias — the same conclusion reached here from the fake-data decomposition of §6.2.

\textbf{Wiener-SVD algorithm cross-check (this work).} The framework unfolder (\texttt{WienerSVDUnfolder.cxx}) was diffed line-by-line against the independent \texttt{RunWienerSVD\_FW} implementation. The two are \textbf{algorithmically identical}: covariance whitening \texttt{Q = chol.GetU()}, response pre-scaling \texttt{R = Q·A}, SVD of \texttt{R·C⁻¹}, Wiener filter \texttt{W = numer/(numer+1)} with \texttt{numer = (D\_C · Vᵀ C x\_prior)²}, and additional-smearing matrix \texttt{A\_C = C⁻¹ V W Vᵀ C}. Feeding the framework's \emph{exact} extracted matrices (smearceptance, prior, data, and full covariance) into a standalone replica of the algorithm reproduces the framework's unfolded result \textbf{bin-for-bin} (Σ x̂ = 5836.5 for cos θ\_μ, A\_C diagonal 0.24). The framework's smearceptance column sums equal the raw efficiency (ratio 1.000) and its prior is the correctly POT-scaled truth (4647.5 = 14179.5 × 0.328). \textbf{There is no framework Wiener-SVD bug.}

\textbf{Interpretation of the \textasciitilde{}1.3× smearing.} Scanning the covariance normalisation shows the unfolded/raw-truth ratio is insensitive to A\_C's over-smearing — even driving A\_C → identity (covariance ×10⁻³, A\_C diagonal → 0.96) leaves x̂/prior = 1.33. The ratio is therefore \emph{not} an A\_C pathology but the combination of the fake-data POT offset (§6.2) and the genuine model normalisation; it cancels in the closure χ² because the predictions are compared in the same A\_C-smeared space (§5.1).

\textbf{Decisive test — numuMC self-closure.} The universes were rebuilt with the numuMC overlay itself in the \texttt{onBNB} slot, so data and response come from the same sample and the detVar-CV POT offset of §6.2 is absent by construction. The unfolded total then recovers the truth for \textbf{all five observables and all three regularisations}:

\section*{8 Open Items}

\textbf{8.1 Cross-section units and bin-width normalisation. — RESOLVED.} \texttt{conversion\_factor()} divided by \texttt{1e39} in NuMI mode against \texttt{1e38} for BNB, and \texttt{Unfolder.C} omitted the bin-width division that \texttt{UnfolderNuMI.C} performs, so the two binaries disagreed on the same bin. Both are now fixed to the BNB convention (10⁻³⁸ cm²/Ar, differential): the NuMI factor is \texttt{1e38}, and \texttt{Unfolder.C} divides each bin by \texttt{conv\_factor × bin\_width × other\_var\_width} via \texttt{SliceHistogram::transform()}, which also converts the covariance. Verified on the costhmu NuWro config that \texttt{Unfolder} and \texttt{UnfolderNuMI} now agree bin-for-bin (ratio 1.0000 across all 12 bins). Relative to earlier output, every cross-section number is \textasciitilde{}10× smaller and now differential.

\textbf{8.2 Beamline geometry systematic.} §4.6.

\textbf{8.3 Anti-neutrino contamination. — CONSISTENT, by construction.} The signal uses \texttt{|mc\_nu\_pdg| == 14}, admitting ν̄μ CC events into signal and the efficiency denominator (the three sibling selections use an exact comparison). With the flux fix (§2.4) the normalising flux is now the \textbf{combined} νμ + ν̄μ flux (4.43515 × 10⁻¹⁰ + 2.37644 × 10⁻¹⁰), and the standalone generators are combined with the same fractions (§6.3). Signal, flux and predictions therefore all treat νμ and ν̄μ together, so there is no longer a normalisation mismatch — the measured quantity is an effective flux-averaged νμ+ν̄μ CC1π cross section. A νμ-only measurement would instead require restricting the signal to \texttt{mc\_nu\_pdg == 14} and using the νμ-only flux; that is a definition choice, not a bug.

\textbf{8.4 Muon BDT. — ACTIVATED.} \texttt{tmvaReader\_mu} was previously constructed and booked but never evaluated. It is now evaluated for every generation-2 track passing the muon-candidate gate, and the muon candidate is chosen as the track with the highest muon-BDT score (previously the longest track). This replaces a purely geometric choice with a PID-informed one; the effect on the selected sample is small (efficiency/purity essentially unchanged, §3.5) because the longest track is usually also the most muon-like, but it makes the muon identification robust in multi-track events.

\textbf{8.5 Flux normalisation. — RESOLVED.} The NuMI flux constant was \textasciitilde{}3.48× too large (§2.4), making cross sections \textasciitilde{}3.5× too small. Corrected to the flux author's authoritative value (6.81159 × 10⁻¹⁰ νμ/cm²/POT, E > 60 MeV) in \texttt{FiducialVolume.hh} and confirmed four independent ways. A residual \textasciitilde{}few-\% active-volume-vs-fiducial-volume approximation is documented in that file.

\textbf{8.6 Fake-data normalisation offset. — DOCUMENTED, uncorrected.} The detVar-CV fake data sits a flat \textasciitilde{}1.29× above the numuMC GENIE tune from a Run-3b-vs-Run-1 POT/flux bookkeeping difference (§6.2). It does not affect the closure and disappears when the real beam-on sample replaces the fake data; the POT correction to remove it (effective POT 9.87 × 10²⁰) is noted in \texttt{file\_properties\_numi.txt}.

\textbf{8.7 Pion momentum estimator bias. — OPEN.} The reconstructed pion momentum uses the muon-hypothesis range momentum (\texttt{track\_range\_mom\_mu}), the only range-momentum branch in the ntuples. It is biased low and increasingly so with momentum (≈ 0 at threshold, −0.15 GeV/c at 0.40; §3.1), from the μ-vs-π mass hypothesis plus pion hadronic re-interaction. The mass part is removable with a pion-hypothesis range correction — a fixed function of the muon-hypothesis momentum, since no \texttt{track\_range\_mom\_pi} branch exists — which would recentre the p\_π response; the re-interaction part is physical and is absorbed by the response matrix, but it motivates the coarse p\_π binning above 0.3 GeV/c (§3.8). The \textbf{momentum thresholds themselves (p\_μ > 0.15, p\_π > 0.175) are validated as correctly placed} at the efficiency turn-on (§3.1).
